Try it yourself

git clone https://github.com/mrabr381/local-pdf-ai.git
cd local-pdf-ai
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/make_sample.py
python -m localpdfai ask --pdf sample_data/sample.pdf --q "What soil pH do tomatoes need?"
Note: neither sample PDF is stored in this repo — both are binary, so the tomato guide is regenerated locally by scripts/make_sample.py and the USDA guide is downloaded from the official link above. That is why this page shows measured numbers in text instead of linking to the PDFs.

Honest limitations

  • Extractive answers quote the document — accurate, but they don't summarise. Generative answers need a local Ollama model (optional).
  • The default TF-IDF backend matches on words, not meaning. Two questions phrased far from the guide's wording missed on top-1 (see qa_report_usda.md). Semantic search is an opt-in (--backend st, needs torch).
  • Scanned image-only PDFs have no extractable text and are rejected — no OCR yet.
