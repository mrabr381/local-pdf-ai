Try it yourself

git clone https://github.com/mrabr381/local-pdf-ai.git
cd local-pdf-ai
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/make_sample.py
python -m localpdfai ask --pdf sample_data/sample.pdf --q "What soil pH do tomatoes need?"
Note: the sample PDF itself is not stored in this repo — it is binary, so it is regenerated locally by scripts/make_sample.py. That is why this page shows measured numbers in text instead of linking to the PDF.

Honest limitations

  • Extractive answers quote the document — accurate, but they don't summarise. Generative answers need a local Ollama model (optional).
  • The default TF-IDF backend matches on words, not meaning. Semantic search is an opt-in (--backend st, needs torch).
  • Scanned image-only PDFs have no extractable text and are rejected — no OCR yet.
